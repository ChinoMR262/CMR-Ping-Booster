Módulos de Red y Arquitectura del Sistema

Implementación técnica fundamentada en estándares RFC y APIs oficiales de Android y Windows.

SPEC DOC · REV 2026
MOD-01
Integridad Zero Anti-Cheat
No abre identificadores de proceso (PROCESS_VM_READ), no inyecta bibliotecas DLL ni analiza la memoria de los juegos. El software actúa exclusivamente sobre la capa de conectividad del sistema operativo.
Compliance 100%
MOD-02
Enrutamiento Anycast DNS
Conmutación local hacia nodos de proximidad geográfica (Cloudflare Gaming, NextDNS, Quad9, Google) reduciendo tiempos de resolución de nombres de servidores de emparejamiento.
Edge BGP Routing
MOD-03
Mitigación de Picos Wi-Fi
Bloqueo dinámico de hardware Wi-Fi (WIFI_MODE_FULL_LOW_LATENCY) para evitar sondeos en segundo plano que introducen microcortes y picos periódicos en partidas multijugador.
Kernel Lock API
MOD-04
Túnel Loopback VpnService
Implementación estricta de la API nativa VpnService de Android en 10.254.1.2, configurada únicamente para capturar paquetes UDP/DNS locales. No opera proxy comercial ni almacena tráfico externo.
Local Loopback
MOD-05
Reversibilidad Inmediata
Al desactivar el booster o cerrar la aplicación, el servicio desengancha las interfaces virtuales y restaura de forma atómica la configuración original de red del dispositivo.
Atomic Clean
MOD-06
Procesamiento 100% Local
La totalidad del cómputo se ejecuta en el dispositivo. No requiere registro de cuentas, no transmite telemetría analítica y no almacena historiales de consultas.
Zero Data Policy

CMR Ping Booster para PC

Diseñado especialmente para jugadores de PC competitivos. Ejecutable autónomo portable de 64-bit para Windows 10 y 11 que optimiza la precisión del reloj del sistema y el flujo Winsock sin instalar drivers de kernel intrusivos.

  • Multimedia Timer a 1.0 ms exactos: Estabiliza la cadencia de fotogramas (frame pacing) y reduce el retardo de sondeo en juegos de disparos y MOBAs.
  • Purga Selectiva de Memoria RAM: Libera conjuntos de trabajo residuales (Working Sets) sin congelar hilos de ejecución activos.
  • Totalmente Desacoplado de Android: Programa de escritorio nativo (.exe) sin dependencias ni servicios ocultos.
  • Cero Riesgo de Baneo: Compatible 100% con Riot Vanguard, Easy Anti-Cheat, BattlEye, VAC y Ricochet.
