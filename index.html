Módulos de Red y Arquitectura del Sistema

Implementación técnica fundamentada en estándares RFC y APIs nativas de Android y Windows.

SPEC DOC · REV 2026
MOD-01
Integridad Zero Anti-Cheat
No abre identificadores de proceso (`PROCESS_VM_READ`), no inyecta bibliotecas ni analiza la memoria de los juegos. El software actúa exclusivamente sobre la capa de conectividad del sistema operativo.
Compliance 100%
MOD-02
Enrutamiento Anycast DNS
Conmutación en caliente hacia nodos de proximidad geográfica (Cloudflare Gaming, NextDNS, Quad9, Google) reduciendo tiempos de resolución de nombres de servidores de matchmaking.
Edge BGP Routing
MOD-03
Mitigación de Picos Wi-Fi
Bloqueo dinámico de hardware Wi-Fi (`WIFI_MODE_FULL_LOW_LATENCY`) para evitar sondeos en segundo plano que introducen microcortes y picos de ping periódicos.
Kernel Lock API
MOD-04
Túnel Loopback VpnService
Implementación estricta de la API nativa `VpnService` de Android configurada únicamente para capturar paquetes UDP/DNS locales. No opera proxy remoto ni almacena tráfico.
Local Loopback
MOD-05
Reversibilidad Inmediata
Al desactivar el booster o cerrar la aplicación, el servicio desengancha las interfaces virtuales y restaura de forma atómica la configuración original de red del dispositivo.
Atomic Clean
MOD-06
Procesamiento 100% Local
La totalidad del cómputo se ejecuta en el dispositivo. No requiere registro de cuentas, no transmite telemetría analítica y no almacena historiales de consultas.
Zero Data Policy

CMR Ping Booster para PC

Diseñado para jugadores de PC competitivos. Ejecutable autónomo portable de 64-bit que no requiere instalación de servicios de fondo ni drivers de red intrusivos.

  • Resolución de temporizador Multimedia Timer a 1.0 ms exactos.
  • Purga selectiva de Working Sets de memoria RAM sin congelar procesos.
  • Integración nativa con la bandeja del sistema (System Tray) en segundo plano.
  • Distribución gratuita y portable de código libre sin telemetría.
