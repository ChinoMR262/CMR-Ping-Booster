Política de Privacidad y Aviso Legal

Última actualización y fecha de vigor: 11 de Septiembre de 2026 · Válido para Google Play Store

1. Identificación del Desarrollador y Aplicación

Esta política de privacidad aplica a la aplicación móvil CMR Ping Booster (Identificador de paquete: com.cmr.pingbooster), desarrollada y mantenida por el equipo de Creative Maximum Reasoning (CMR).

2. Declaración de Recopilación y Uso de Datos

CMR Ping Booster es una aplicación 100% privada y local.

  • Cero recolección de datos personales: No solicitamos ni recopilamos nombres, correos electrónicos, números telefónicos, listas de contactos ni identificadores de hardware.
  • Cero seguimiento de tráfico: No se registra, almacena, analiza ni transmite el historial de navegación, nombres de dominio ni la actividad web realizada en el dispositivo.
  • Sin servidores intermediarios externos: La aplicación no reasigna la conexión a través de ningún servidor proxy ni VPN propio de recopilación de datos.
  • Sin SDKs ni analíticas publicitarias de terceros: La aplicación carece de código de rastreo comercial o anuncios.

3. Declaración de Uso del Servicio VpnService (Google Play Policy)

En estricto cumplimiento con las políticas para desarrolladores de Google Play respecto al permiso android.permission.BIND_VPN_SERVICE (VpnService API):

  • Propósito exclusivo de la API VpnService: CMR Ping Booster utiliza la API VpnService para establecer un túnel de interfaz en bucle local (Loopback VPN) dentro del sistema operativo Android. Su único propósito técnico es interceptar y enrutar las solicitudes de resolución de nombres de dominio (DNS) hacia servidores DNS Anycast optimizados para juegos (como Cloudflare 1.1.1.1, Quad9 9.9.9.9 o Google 8.8.8.8).
  • No es una VPN tradicional de tunelización completa: No redirige el tráfico de datos generales de Internet a través de un servidor remoto, no cifra el tráfico de otras aplicaciones ni oculta la dirección IP real del usuario.
  • Transparencia y control total: El usuario puede activar y desactivar la VPN local de manera voluntaria e instantánea mediante la interfaz principal de la app. Al desactivar el booster, la VPN local se destruye inmediatamente y la configuración de red retorna al estado predeterminado del sistema.

4. Permisos Requeridos por el Sistema Android

INTERNET: Permite resolver consultas DNS nativas y verificar la latencia estimada mediante sockets locales.
ACCESS_NETWORK_STATE & ACCESS_WIFI_STATE: Permiten detectar si el dispositivo está conectado por Wi-Fi o datos móviles para adaptar los perfiles de buffer.
POST_NOTIFICATIONS (Android 13+): Utilizado exclusivamente para mostrar el estado del servicio activo en la barra de estado.

5. Versión de Escritorio para PC (Complementaria y Gratuita)

CMR Ping Booster ofrece de manera complementaria una versión portable para sistemas Microsoft Windows PC. Dicha versión es de distribución libre y gratuita, operando de forma autónoma a través de APIs de red nativas de Windows sin inyección de memoria ni interacción con el ejecutable de Android.
