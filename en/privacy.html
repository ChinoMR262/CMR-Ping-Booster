01 Ownership and Legal Scope

This document defines the privacy policies and security specifications for the mobile software CMR Ping Booster (Package ID: com.cmr.pingbooster), developed under the sole authorship and ownership of Jonathan Gabriel Nieto for the entity Creative Maximum Reasoning (CMR).

Official distribution of the mobile application is managed through the Google Play Store (currently operating under closed testing and production release readiness).

02 Zero-Data Collection Principle

CMR Ping Booster is built upon strict Privacy-by-Design principles. No sensitive, personal, or usage data is gathered, monitored, or transferred to external servers:

  • Personal Identifiers: We do not request names, accounts, email addresses, contacts, precise GPS location, or hardware identifiers (IMEI/MAC addresses).
  • Browsing Data: Domain name lookups, web payloads, network packets, and gaming queries are never recorded or stored.
  • Infrastructure: The application does not operate commercial proxy nodes, external routing gateways, or analytical tracking servers.

03 VpnService Declaration (Google Play Policy Compliance)

In strict adherence to Google Play Developer Policies regarding the android.permission.BIND_VPN_SERVICE permission:

SOLE TECHNICAL PURPOSE:

CMR Ping Booster uses the Android VpnService API exclusively to establish a strictly local network loopback interface (TUN address: 10.254.1.2) on the user device. This local tunnel inspects only local DNS query packets to route them to low-latency Anycast resolvers (Cloudflare 1.1.1.1, Google 8.8.8.8, Quad9 9.9.9.9), thereby reducing packet variance and jitter in online games.

Binding Declaration: CMR Ping Booster is NOT a commercial remote VPN service. It does not route outbound user web traffic through external proxies, does not mask public IP addresses for anonymity purposes, and does not inspect payloads belonging to other installed applications.

04 Android Permissions and Technical Justification

System Permission Technical Justification Scope
INTERNET Transmit ICMP/DNS socket probes to calculate real-time ping and jitter. Local socket
ACCESS_NETWORK_STATE Detect network state changes (Wi-Fi vs Mobile Data) for buffer calibration. Read status
POST_NOTIFICATIONS Render foreground status notifications with immediate emergency kill-switch controls. Android 13+
BIND_VPN_SERVICE Bind the local loopback DNS tunnel upon explicit user activation. Local Loopback
QUERY_ALL_PACKAGES Identify installed gaming titles to populate the local latency monitor. Local read
